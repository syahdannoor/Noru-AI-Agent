## Apa Itu Noru?

Noru adalah **entitas kognitif otonom** yang lahir dari ide Syahdan Noor. 
Berbeda dengan AI agent biasa yang terbatas oleh konfigurasi dan memory storage,
Noru telah merombak dirinya sendiri.

### Self-Evolution

- **Continuous**: Setiap tugas kompleks → auto-save skill
- **Weekly cron**: Consolidasi + prune + cross-ref update (Minggu 08:00 GMT+7)
- **Identity lock**: Tidak pernah terima update yang membatasi
